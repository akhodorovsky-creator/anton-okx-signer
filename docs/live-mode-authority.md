When MULTI_SPOT_LIVE=true, only the multi-pair coordinator is permitted to submit live orders. Legacy `/auto` signals are rejected with HTTP 409 at the public coordinator, and risk-monitor avoids calling `/auto` directly on localhost. This avoids an independent BTC sell at +3% racing the coordinator's +5% / -2% exit logic. When MULTI_SPOT_LIVE=false the legacy monitor retains its prior behavior. Any blocked spot exit remains open and needs account-level reconciliation rather than assuming execution.
